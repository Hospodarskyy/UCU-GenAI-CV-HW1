# GenCV Homework 1

Generative models for images, trained on MNIST and FashionMNIST.

- [Norm Flow](Norm%20Flow/) - RealNVP normalizing flow
- [VAE](VAE/) - autoencoders, VAE, f-VAE and β-VAE
- [GAN](GAN/) - vanilla GAN, conditional GAN, PatchGAN and feature matching

Each folder has its own README with my explanation, results and observations.
